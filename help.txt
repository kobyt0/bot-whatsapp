📖 *Menú de comandos*
Prefijo: *!*  ·  🛡️ = solo admins

*🛡️ Filtros y protección*
• *!bot* on|off 🛡️
  → Activar o desactivar el bot
• *!onlyadmin* on|off 🛡️
  → Solo los admins pueden usar comandos
• *!antilink* on|off 🛡️
  → Borra mensajes con enlaces
• *!economy* on|off 🛡️
  → Activa o desactiva la economía
• *!gacha* on|off 🛡️
  → Activa o desactiva el sistema gacha
• *!comando* <comando> on|off 🛡️
  → Activa o desactiva un comando en el grupo
• *!mute* 30m|1h|1d|1w @usuario 🛡️
  → Silencia a alguien (el bot borra sus mensajes)
• *!unmute* @usuario 🛡️
  → Quita el silencio a un usuario
• *!mutes* 🛡️
  → Lista de usuarios silenciados

*👮 Administración*
• *!promote* @usuario 🛡️
  → Hace admin a un miembro
• *!demote* @usuario 🛡️
  → Quita el admin a un miembro
• *!kick* @usuario 🛡️
  → Expulsa a un miembro
• *!close* 🛡️
  → Solo los admins pueden escribir
• *!open* 🛡️
  → Todos pueden escribir
• *!delete* (responde a un mensaje) 🛡️
  → Borra un mensaje
• *!todos / !tagall* [texto] 🛡️
  → Menciona a todos sin mostrar los @ (alias: !tag)
• *!setnamegroup* <nombre> 🛡️
  → Cambia el nombre del grupo
• *!setpfp* (imagen) 🛡️
  → Cambia la foto del grupo
• *!setprefix* <prefijo> 🛡️
  → Cambia el prefijo de comandos del grupo

*⚠️ Advertencias*
• *!warn* @usuario [motivo] 🛡️
  → Pone una advertencia
• *!unwarn* @usuario 🛡️
  → Quita una advertencia
• *!resetwarn* @usuario 🛡️
  → Borra todas las advertencias de alguien
• *!setwarnlimit* <1-20|off> 🛡️
  → Advertencias para la expulsión automática
• *!warns* @usuario
  → Ver las advertencias de alguien
• *!mywarns*
  → Ver tus advertencias
• *!allwarns*
  → Lista de advertencias del grupo

*👋 Bienvenida y banner*
• *!welcome* on|off 🛡️
  → Activa o desactiva la bienvenida
• *!goodbye* on|off 🛡️
  → Activa o desactiva la despedida
• *!setwelcome* <texto> 🛡️
  → Personaliza el mensaje de bienvenida
• *!setgoodbye* <texto> 🛡️
  → Personaliza el mensaje de despedida
• *!setbanner* (imagen) 🛡️
  → Imagen para bienvenida y despedida (reset para quitarla)

*💰 Economía*
• *!saldo / !balance* [@usuario]
  → Tu dinero (efectivo y banco)
• *!daily*
  → Recompensa diaria con racha
• *!work / !trabajar*
  → Trabaja para ganar coins
• *!slut*
  → Gana coins con encanto (puede salir mal)
• *!crime*
  → Comete un crimen (puede salir mal)
• *!robar / !rob* @usuario
  → Intenta robar efectivo a alguien inactivo
• *!deposit / !depositar* <monto|all|half>
  → Guarda efectivo en el banco
• *!retirar / !withdraw* <monto|all|half>
  → Saca dinero del banco
• *!pay* <monto> @usuario
  → Envía coins a otro usuario
• *!baltop*
  → Ranking de los más ricos
• *!setcoins* <nombre|reset> 🛡️
  → Cambia el nombre de la moneda del grupo
• *!reseteconomy* 🛡️
  → Reinicia la economía del grupo
